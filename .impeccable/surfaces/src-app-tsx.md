## Direction contract

THESIS: The dashboard is a wire desk, not a card grid — incidents arrive as timestamped bulletins on one continuous append-only feed, because that discipline is exactly what an audit trail needs. Refuses the generic-SaaS status-card default.

OWN-WORLD: Manila/steel palette, near-monochrome; true monospace carries hierarchy by weight/size; wire precedence codes (FLASH/URGENT/BULLETIN/ROUTINE) replace generic severity chips; one hot accent reserved only for live/unresolved state.

STORY: Responder scans the feed top-down, most urgent/most recent first; claims an incident (stamps a visible mark); watches mitigation TTL as a live countdown against a persistent running clock; every action punches a new line, never edits history.

FIRST VIEWPORT: Single continuous vertical feed under a machine-panel header (nameplate + live heartbeat indicator); each bulletin fixed-width, precedence code leading, whole row interactive.

FORM: Telex/wire-desk (candidate 7 of 7 own-ranked; catalog challengers all declined, raises folded in: mechanical motion cadence, persistent now-reference, claim-as-stamp, typography-led hierarchy); seed key 8fda45e2.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
